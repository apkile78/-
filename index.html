Babylon.js browser test runner

A small demo is ready. Click Run, or select your game .js file.
How this works and limitations

Load your .js file or paste it on the left, then click Run. Each run creates a fresh iframe. No terminal or deployment is needed between tests. Click inside the game to use its mouse controls; press Esc to release pointer lock.

This runner supports self-contained Babylon scene factories using the global BABYLON and engine objects. Export createScene or use a top-level createScene function. Relative imports, npm package imports, local asset folders, and arbitrary Vite projects are not automatically resolved.

The runner itself does not upload selected code. It downloads Babylon.js from its public CDN, and the code you run can make its own network requests. Only run code you trust: this iframe is for lifecycle isolation, not a security boundary. Game initialization and shader compilation still take their normal time.

This HTML file contains its own editor and runner, not the planet game. The initial sphere demo is just a runner check. Saving exports a .js file. Edits are not automatically saved; download them before closing or refreshing.
